# Student-Registration-Swing.java
Java Swing GUI application for student registration with input validation and event handling.
A simple Java Swing-based Student Registration System developed using Java.

## Features

- Student name input
- Roll number input
- Gender selection
- Branch input
- Terms and conditions acceptance
- Input validation
- Registration success message
- Reset functionality

## Technologies Used

- Java
- Java Swing
- AWT Event Handling

## How to Run

Compile the Java file:

javac StudentRegistration.java

Run the program:

java StudentRegistration
