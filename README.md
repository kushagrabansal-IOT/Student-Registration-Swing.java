# Student-Registration-Swing.java
Java Swing GUI application for student registration with input validation and event handling.
A simple Java Swing-based Student Registration System developed using Java.

## Features

- Student name input
- Roll number input
- Gender selection
- Branch input
- Terms and conditions acceptance
- Input validation
- Registration success message
- Reset functionality

## Technologies Used

- Java
- Java Swing
- AWT Event Handling

## How to Run

Compile the Java file:

javac StudentRegistration.java

Run the program:

java StudentRegistration
# Student Registration System Using Java Swing

## About

This project demonstrates the development of a **Student Registration System using Java Swing**. It focuses on creating a graphical user interface (GUI) through which users can enter student details using registration forms and input fields.

Java Swing provides the components required to build the interface, such as labels, text fields, buttons, and other form elements. The project helps demonstrate how Java applications can collect user input and process it through event handling.

## Objectives

- Develop a student registration form using Java Swing.
- Understand graphical user interface (GUI) development in Java.
- Create form elements for entering student information.
- Handle user interactions using Java event handling.
- Apply object-oriented programming concepts.
- Understand how desktop applications collect and process user input.

## Technologies Used

- **Programming Language:** Java
- **GUI Framework:** Java Swing
- **Concepts:** Object-Oriented Programming, Event Handling, and Form Design
- **Tools:** JDK and a Java IDE

## Key Concepts

- **JFrame:** Creates the main application window.
- **JLabel:** Displays labels for student information fields.
- **JTextField:** Allows users to enter text.
- **JButton:** Provides buttons for user actions.
- **Event Handling:** Responds to button clicks and other interactions.
- **Form Design:** Organizes input fields into a structured registration interface.

Through this project, I gained practical experience in designing Java Swing interfaces, creating input forms, handling user interactions, and organizing GUI components within a desktop application.
